# 营养平衡评估流程

## Overview

基于日/周/月时序聚合饮食记录，评估营养平衡状况，计算 RNI 达成率、缺口/过量、平衡评分、多样性评分。

## When to Use

- 用户说"评估营养"、"看看平衡"、"我缺什么"、"本周营养怎么样"
- 用户想了解一段时间内的营养摄入是否合理
- 用户想查看营养缺口或过量

## Workflow

### 1. 确定周期
与用户确认评估周期：
- daily: 今日
- weekly: 本周（最近7天）
- monthly: 本月（最近30天）
- 也可指定 start_date / end_date

### 2. 执行评估
调用 `assess_balance` Tool，返回：
- 总摄入 / 日均摄入
- 各营养素 RNI 达成率
- 平衡评分（0-100）
- 营养缺口（<80% RNI）/ 过量（钠/胆固醇 >150%）
- 饮食多样性评分
- 规则建议

### 3. 展示结果
- 平衡评分仪表盘
- 营养达成率雷达图
- 缺口/过量清单（按严重度排序）
- 基础建议

### 4. 生成个性化建议（可选）
使用返回的 `assessment_prompt` 调用 LLM 生成个性化建议。

## Quick Reference

| 步骤 | Tool | 说明 |
|------|------|------|
| 平衡评估 | `assess_balance` | 返回评估结果 + LLM prompt |
| 个性化建议 | LLM + `assessment_prompt` | 生成可执行建议 |

## 评估标准

- 平衡评分：达成率在 [0.8, 1.5] 得满分，平均 ×100
- 不足：达成率 <80% RNI
- 过量：钠/胆固醇达成率 >150%
- 多样性：每天 12 种以上食物为 100 分
