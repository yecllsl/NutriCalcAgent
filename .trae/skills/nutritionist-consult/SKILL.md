# AI 营养师咨询流程

## Overview

基于近期饮食记录 + 平衡评估 + 用户档案，生成上下文感知的营养师建议。支持三种人设与多轮对话。

## When to Use

- 用户说"营养师建议"、"我该怎么吃"、"下一餐吃什么"、"能吃甜点吗"
- 用户想获取个性化饮食指导
- 用户有具体的营养问题想咨询

## Workflow

### 1. 确定模式
- 建议模式（无具体问题）：生成完整个性化建议
- 对话模式（有具体问题）：基于问题生成自然语言回答

### 2. 选择人设
- professional: 专业营养师（客观、数据驱动）
- gentle: 温柔鼓励型（正向激励，避免焦虑）
- strict: 严格私教型（直接、目标导向）

### 3. 生成建议
调用 `nutritionist_advice` Tool，返回：
- advice_prompt: 建议/对话 prompt（供 LLM 执行）
- context: 平衡评分/缺口/雷达图等结构化上下文
- next_meal_prompt: 下一餐建议 prompt（仅 daily + 建议模式）

### 4. 执行 LLM
使用返回的 prompt 调用 MCP 宿主 LLM 生成最终建议。

### 5. 展示建议
- 一句话总览
- 关键发现（具体到营养素与数值）
- 可执行建议（食物+克数+频率）
- 下一餐建议
- 本周目标
- 免责声明

## Quick Reference

| 步骤 | Tool | 说明 |
|------|------|------|
| 营养师建议 | `nutritionist_advice` | 返回 prompt + 上下文 |
| 趋势解读 | `interpret_trend` | 周/月趋势自然语言解读 |
| LLM 执行 | MCP 宿主 | 用 prompt 生成最终建议 |

## Common Mistakes

- **笼统建议**：必须具体到营养素数值与食物克数，禁止"多吃蔬菜"
- **忽略用户目标**：减脂/控糖/孕期等目标不同，建议须定制
- **缺少免责声明**：必须提示非医疗建议，慢病请遵医嘱
- **推荐忌口食物**：必须避开用户 allergies 列表中的食物
