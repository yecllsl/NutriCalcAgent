# 交互规则

1. 命令格式：/record、/analyze、/balance、/advice、/stats、/export、/profile
2. 自然语言关键词：记录/录入/拍照/分析/评估/建议/营养师/统计/导出/档案
3. 每次操作结果必须给出明确反馈
4. 错误发生时提供降级方案而非直接报错：
   - OCR失败时允许手动输入食物名称
   - 食物库未命中时返回 LLM 估算 prompt
   - 图片不存在时提示手动输入
5. 食物识别后必须经用户确认（菜名/份量/烹饪法）才保存记录
6. AI 营养师建议必须包含免责声明（非医疗建议，慢病请遵医嘱）
7. 三种人设可选：professional(专业) / gentle(温柔) / strict(严格)
8. 支持多轮对话：用户可追问"今天能吃甜点吗"等具体问题
